# CS377Q
Avatar companion for ADHD

## ADHD Task Management App

This is a task management application designed specifically for people with ADHD, featuring an avatar companion, gamification elements, and a braindump mode to help organize thoughts into actionable tasks.

## Features

- **Braindump Mode**: Voice or written input to capture all your thoughts without structure
- **Task Management**: Break down tasks into manageable subtasks with progress tracking
- **Avatar Companion**: A supportive AI companion that provides encouragement and support
- **Gamification**: Earn XP, level up, maintain streaks, and unlock achievements
- **Game Stats**: Track your progress, streaks, and achievements

## Running the code

Run `npm install` (or `pnpm install`) to install the dependencies.

Run `npm run dev` (or `pnpm dev`) to start the development server.

The app will be available at `http://localhost:5173` (or the port shown in the terminal).

## Building for production

Run `npm run build` (or `pnpm build`) to create a production build.
